# 📡 الناقل البصري (Optical Transfer)

انقل الملفات بين موبايلين **بدون إنترنت، وبدون Wi-Fi، وبدون Bluetooth** باستخدام الكاميرا وشاشة الـ QR المتحركة!

## 🚀 المميزات
- ضغط الملفات قبل الإرسال.
- تقطيع الملف لقطع صغيرة (زي التورنت).
- مقاومة فقدان الإطارات (يتجاهل التكرار).
- واجهة عربية بسيطة.

## 📲 طريقة التشغيل
1. افتح الموقع على الموبايل الأول (مرسل).
2. اختر ملف واضغط "بث".
3. افتح الموقع على الموبايل الثاني (مستقبل).
4. شغّل الكاميرا ووجّهها للشاشة الأولى.
5. استلم الملف واضغط "تحميل".

## 🛠️ تقنيات مستخدمة
- HTML / CSS / JavaScript
- jsQR (فك الأكواد)
- QRCode.js (توليد الأكواد)
- PWA (يعمل كتطبيق)

## 📦 التثبيت كتطبيق
- افتح الموقع في كروم ← "إضافة إلى الشاشة الرئيسية".
- أو استخدم PWABuilder لإنشاء APK.
